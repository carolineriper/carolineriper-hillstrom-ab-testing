# Hillstrom A/B Testing

Учебно-портфельный анализ рандомизированного e-mail эксперимента Hillstrom. Проект сравнивает две маркетинговые кампании — `Mens E-Mail` и `Womens E-Mail` — с контрольной группой `No E-Mail`.

## Цель проекта

Оценить, увеличивают ли рассылки:

- средние траты на пользователя (`spend`, primary metric);
- конверсию в покупку (`conversion`);
- долю пользователей с визитом (`visit`).

Анализ построен как законченный A/B-проект: от проверки качества данных и рандомизации до оценки эффектов, множественных сравнений и применимости CUPED.

## Что сделано

- разделены pre-treatment, treatment и post-treatment признаки;
- зафиксированы параметры анализа: `alpha = 0.05`, `power = 0.80`, two-sided tests;
- проверены качество данных и логическая согласованность метрик;
- проведён SRM-тест для ожидаемого распределения 1/3–1/3–1/3;
- проверен pre-treatment баланс с помощью SMD и нормированных crosstab;
- выполнен ретроспективный MDE / sensitivity analysis для `spend`;
- рассчитаны абсолютные и относительные uplift;
- построены bootstrap 95% CI для разницы средних трат;
- выполнены Welch t-tests для `spend` и z-tests для долей;
- p-value скорректированы методом Holm для двух сравнений с контролем;
- оценена применимость классического одномерного CUPED.

## Основные результаты

| Метрика | No E-Mail | Mens E-Mail | Womens E-Mail |
|---|---:|---:|---:|
| Spend per User | 0.6528 | 1.4226 | 1.0772 |
| Conversion | 0.5726% | 1.2531% | 0.8837% |
| Visit | 10.6167% | 18.2757% | 15.1400% |

- `Mens E-Mail` увеличил Spend per User на 0.7698, или 117.93% относительно контроля.
- `Womens E-Mail` увеличил Spend per User на 0.4244, или 65.02%.
- Bootstrap 95% CI для uplift: `[0.4937; 1.0610]` и `[0.1683; 0.6854]`.
- После Holm correction обе кампании статистически значимо превосходят контроль по `spend`, `conversion` и `visit`.
- Men's показывает больший наблюдаемый эффект, но превосходство Men's над Women's не утверждается без отдельного прямого теста.

## CUPED

Доступные pre-treatment признаки почти не связаны с post-treatment `spend`. Максимальная абсолютная корреляция в контрольной группе составляет около `0.0243`, то есть `rho² ≈ 0.00059` — примерно 0.06% объясняемой линейной вариации.

Вывод: данные методологически позволяют построить CUPED-корректировку, но ожидаемое снижение дисперсии пренебрежимо мало, поэтому применять классический одномерный CUPED ради формального наличия метода нецелесообразно.

## Ограничения

- В данных нет временных меток и дневного трафика, поэтому traffic-based duration восстановить нельзя. Документированное окно наблюдения — 14 дней.
- Отсутствуют guardrail-метрики: unsubscribe, complaints, churn и другие негативные сигналы.
- В датасете нет `customer_id`, поэтому полностью одинаковые строки нельзя надёжно классифицировать как дубли пользователей.
- MDE рассчитан ретроспективно по фактической post-treatment дисперсии и не является pre-test планированием.
